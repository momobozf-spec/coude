# Pijler 2 — Boete aanvechten *(nog niet gebouwd)*

Gereserveerde plek voor het bezwaarschrift tegen parkeerretributies.

Wat hier hoort te komen: de pure beslislogica — welk bezwaarscenario van
toepassing is (geldige bewonerskaart, betaald ticket, blauwe schijf,
plaatwijziging), welke bewijsstukken dat scenario vereist, of een bezwaar binnen
de termijn valt, en hoe de argumentatie opgebouwd wordt.

## Bestaand materiaal in de werkruimte

`../../../parking-brussel-helper/` (naast dit project) is een statisch prototype
met bruikbare domeinkennis: de Brusselse parkeerzones met retributiebedragen, een
bewijsstukkenchecklist per scenario, en de officiële Parking.brussels-routes.

Het is een prototype zonder bronvermelding, geen bron. Elk feit dat eruit
overgenomen wordt, hoort — net als bij de gemeente-registry — tegen een officiële
pagina gelegd te worden voordat het als geverifieerd geldt. Zie
`docs/gemeenten.md` voor de werkwijze.

Let op: parking.brussels sloot zijn e-mailkanaal op 16-03-2026. Bezwaren lopen
via het officiële klachtenformulier. Dezelfde beperking als bij module 3 geldt
hier dus waarschijnlijk ook — ADR 0005 is het startpunt.
