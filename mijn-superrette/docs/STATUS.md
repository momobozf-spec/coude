## Not yet built (next steps)

- App Store / Google Play subscription verification and notifications.
- E-mail verification, password reset, admin 2FA.
- Push receipt checking, retention jobs.
- Store locations and regions in pricing (the schema supports them; promotions already support `regionCodes`).
- User-submitted barcode metadata. Brand and synonym management UI in the admin (currently DB only).
- Travel distance / fuel cost in Smart Basket (the `extraStoreCostCents` hook exists).
- Native device QA (iOS/Android), accessibility audit, performance testing with production-sized catalogues.
