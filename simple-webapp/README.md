# Simple Web App

Een kleine starter-webapp zonder dependencies. Je kunt dit direct openen in je browser en daarna met Claude Code verder uitbouwen.

## Starten

1. Open `index.html` in je browser.
2. Voeg taken toe, vink ze af en verwijder ze.
3. De taken blijven bewaard via `localStorage`.

## Structuur

- `index.html` bevat de layout
- `styles.css` bevat de styling
- `app.js` bevat de logica

## Handige prompts voor Claude Code

- "Voeg een filter toe voor alle, open en afgeronde taken."
- "Maak van deze taken-app een notitie-app."
- "Voeg een donkere modus toe."
- "Zet deze app om naar React."
