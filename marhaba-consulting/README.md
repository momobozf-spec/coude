Nederlandstalige, responsive consultingwebsite met interactieve bedrijfsvoorbeelden, mobiele navigatie, FAQ en lokale projectbriefdownload. HTML, CSS en JavaScript; geen buildstap of npm-dependencies.

## Lokaal starten

```powershell
cd marhaba-consulting
npm.cmd run dev
```

Open http://localhost:3015. Met `PORT` kan de poort worden aangepast. `npm.cmd run check` controleert de JavaScript-syntax.

## Publiceren

Plaats `index.html`, `styles.css`, `app.js` en `favicon.svg` op een statische webhost. De Node-server is alleen voor lokale preview. Fonts worden geladen via Google Fonts, met lokale systeemfonts als fallback.

## Contactformulier

Er is nog geen bevestigd zakelijk e-mailadres. Daarom maakt het formulier expliciet een lokaal tekstbestand en verzendt het niets. Voor echte contactaanvragen moet een bevestigd adres of formulierbackend worden aangesloten. De interactieve voorbeelden tonen mogelijke verbetertrajecten, geen behaalde klantresultaten. Data en AI ondersteunen de zakelijke positionering.
